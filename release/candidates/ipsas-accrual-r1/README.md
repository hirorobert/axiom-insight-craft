# IPSAS NGO preparation candidate

Executable development foundation. **Not a complete IPSAS product, compliance certification, approved report, or live feature.** No production module imports this directory. The kernel adapter always returns `publicationAuthorized: false`.

Implemented: strict period/adoption profiles; evidence-bound two-period trial balances and explicit presentation assignments; exact integer monetary computation; financial position, performance, aggregate changes in net assets and gross direct cash-flow preparation; opening bridges without plugs; bounded fixed fully funded monetary grants; scoped FX translation; public-budget reconciliation; explicit completion tasks across 35 accounting topics; immutable source and separate accounting/provenance digests. Four draft statements can be assembled through the existing canonical proof kernel and checked independently.

The 35-topic inventory is not paragraph-level standards coverage. Evidence actors supplied in local JSON are not verified sign-ins. Trial balance completeness and accounting decisions remain supplied assertions. The canonical performance type is the existing profit-or-loss type with an IPSAS preparation title; budget stays separate, notes and policies are empty, and all output is marked incomplete. Comparative arithmetic does not settle transition/restatement requirements. No production compiler, schema, signing digest, SQL, customer AI or access setting changes.

## Run locally

From repository root, after the normal frozen-lockfile installation:

```
bun run test src/lib/frameworkPacks/ipsasAccrualCandidate.test.ts
bunx tsc --noEmit -p release/candidates/ipsas-accrual-r1/tsconfig.json
bun run release/candidates/ipsas-accrual-r1/demo.ts docs/release/ipsas-accrual-r1/fixtures/synthetic-ngo.json /tmp/ipsas-ngo-result.json
```

The demo refuses to overwrite an existing output. It uses local fixtures and no API. All fixture actors, assessments and legal eligibility assertions are fictional; source hashes bind the actual CSV/workpaper bytes.
