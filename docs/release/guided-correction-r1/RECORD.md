## Implemented

The correction action is visually distinct from finding dispositions. Each disposition and comments have plain-language consequences. Selecting another finding clears the prior finding's notice and text. Category guidance explains cost of sales, asset deductions and maturity uncertainty without selecting a classification. A user-requested reason template is built from the actual selected categories, never an invented accounting justification. Its instructional placeholder must be replaced before submission. Existing canonical receipts, scope ownership, retry identities, permission checks and explicit recheck are preserved.

No classifier, database, migration, function closure, financial amounts, reporting activation or AI settings change.
