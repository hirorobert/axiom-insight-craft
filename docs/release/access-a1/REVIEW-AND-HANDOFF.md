# access-a1 — production migration packaging repair (substantive review + Lovable handoff)

## What was wrong
Merged PR #130 added `supabase/migrations/20261104100000_platform_owner_access_and_entity_allowance.sql` with an embedded
`BEGIN; … COMMIT;`. The authoritative hosted runner applies each migration through a **self-checking wrapper** — one `DO`
block that `EXECUTE`s the migration bytes and records its journal row in the SAME transaction. Transaction-control
statements are illegal inside `EXECUTE`/a `DO` block, so the runner rejects an embedded `BEGIN/COMMIT`. Every migration since
`20261011100000` therefore contains **no** transaction-control statement (verified); PR #130's did, so it could not be
applied.

## The repair (smallest compatible; reviewed pattern, not ad hoc)
1. **Source** `20261104100000` — removed the two transaction-control statements only; added a packaging note. **No SQL logic
   changed** (diff is exactly `-BEGIN;` / `-COMMIT;` + a comment). Atomicity is **not** lost: it moves to the wrapper's single
   `DO` statement (atomic on its own) and the runner's one transaction, exactly as the ten prior wrapped releases.
2. **Wrapper** `release/wrappers/20261104100000_platform_owner_access_and_entity_allowance.wrapper.sql` — generated by
   `scripts/release/selfCheckingWrapper.mjs` from the committed source bytes at `8a5c0e13`. Before any statement runs it
   recomputes the enclosed payload's byte count + SHA-256 and refuses (SQLSTATE 55000, nothing changed) unless both match.
3. **Registration** — batch `access-a1` in `selfCheckingWrapper.mjs`; both source forms and both wrapper forms in
   `SUBMISSION_FORMS` (`scripts/ci/releaseJournal.mjs`); the read-only postcondition in `docs/release/access-a1/`.
4. **Not marked applied.** No `drizzle/migrations` entry and no `RELEASE_JOURNAL` entry were added — the migration remains
   **PENDING** (`migrationAuthority`/`releaseJournal` list it as pending; the wrapper is registered-before-application). The
   hosted journal row is created only when Lovable actually applies it.
